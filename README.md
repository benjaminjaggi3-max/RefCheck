# RefCheck

RefCheck prüft, ob eine Punktwolke georeferenziert ist. Nutzer können E57-, TXT- oder CSV-Dateien lokal hochladen und die Daten direkt im Browser analysieren. Die App erkennt CRS-/Georeferenzierungs-Metadaten und bewertet die Koordinaten auf Großräumigkeit.

## Features
- Upload von E57-, TXT- und CSV-Dateien
- Lokale Analyse im Browser
- Georeferenzierungsprüfung
- Punktwolkenvisualisierung

## Stack
- HTML
- CSS
- JavaScript

## Hosting
RefCheck ist als statische Browser-App für GitHub Pages und Cloudflare Pages geeignet.
